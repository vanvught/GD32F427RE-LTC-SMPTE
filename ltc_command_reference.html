LTC command reference

Derived from the supplied C++ sources · grouped in shell::kCommandTable order · 35 command rows + UDP port reference

Protocol conventions: UDP text commands begin with ltc!, midi!, gps!, or tcnet!. OSC paths begin with /{hostname}/tc/; OSC numeric arguments are binary arguments, not path text. UART commands are one line each. A dash indicates no OSC handler was established.

TCNet OSC addresses use slash-separated path values, unlike the # separators in UDP and UART commands. No OSC arguments are required for these three commands.

Implementation notes: TCNet UDP, UART and OSC paths are represented. The OSC dispatcher handles /tcnet/layer/<value>, /tcnet/type/<value>, and /tcnet/timecode/<value> and calls TCNet setters directly. Ensure SetLayer, SetType and SetUseTimecode are declared in ltc_actions.h (the earlier uploaded header declares only HandleAction). The TCNet layer alphabet is defined outside the supplied files; layer A is illustrative. The port table covers the five constants in ltc_udp_port.h.
