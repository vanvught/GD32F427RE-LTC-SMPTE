The TCNet, Internal and System-Time output enum values have no start/stop entries and are intentionally omitted from the matrix. Their names exist in ltc.h, but StartEnabled() marks outputs without start handlers disabled. The matrix is a configuration/dispatch summary, not a hardware or end-to-end interoperability test.

Implementation notes

Single active input: Source::Select() stops the previous input, calls Destination::Update(input) , resets timecode state, then starts the new input. Update() forces the output with the same input bit off in the current enabled mask, preventing same-protocol forwarding while that input is selected. A later explicit output enable may change this state.

Output dispatch: Destination::Distribute() explicitly calls LTC and Art-Net outputs, then DistributeInternal() handles MIDI-family timecode, NTP server, and displays. ETC has a start/stop registration but is not explicitly dispatched in these functions. TCNet has an input handler, but no output start/stop registration.

System-Time: kSystime is an input source, not a registered output. The README lists GPS and NTP/PTP under system-time input.

Default configuration: The pixel display output is initially marked disabled. Other outputs are subject to start-up initialization and runtime enable/disable state.

Supported timecode formats: Film 24 fps, EBU 25 fps, DF 29.97 fps, and SMPTE 30 fps.
